# Personal Library (CLI Python Application)

A command-line application for managing a personal library. Users can add, search, update, remove, check out, and return books while automatically saving their library between sessions.

## Purpose

The purpose of this project is to practice fundamental Python programming concepts by building a complete application with persistent data storage and an object-oriented design.

## Features

The application allows users to:

- View all books in the library.
- Add a new book.
- Search for books by title or author.
- Update book titles and authors.
- Check out and return books.
- Delete books from the library.
- Save the library to a JSON file.
- Automatically load the library when the program starts.
- Exit the application safely.

## Technologies

- Python 3
- JSON
- Pytest
- Git
- VS Code

## Installation

1. Clone or download the repository.
2. Navigate to the project directory.
3. Create and activate a virtual environment.
4. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Running the Project

After activating the virtual environment, run:

```bash
python main.py
```
